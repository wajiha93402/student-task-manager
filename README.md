# Student Task Manager

A simple Python command-line application that helps students organize their academic tasks and assignments.

### Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks locally using JSON file handling

### Technologies Used
- Python
- JSON
- File handling
- Functions and loops
- Conditional statements
- Exception handling


### Learning Objectives
This project was created to practise Python fundamentals and develop problem-solving skills while building a useful tool for students.

### Future Improvements
- Add task deadlines and priorities
- Build a graphical user interface
- Add search and filtering
- Generate a summary of completed and pending tasks
